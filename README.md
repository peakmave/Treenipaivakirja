# Treenipaivakirja

Keskeiset toiminnot
- Käyttäjän rekisteröityminen ja kirjautuminen
- Treenien lisääminen, muokkaaminen ja poistaminen
- Voimaharjoitteluliikkeiden kirjaaminen sarjoineen, toistoineen ja painoineen
- Oma treenihistoria ja yksinkertaiset tilastot/kehitysseuranta
- Treeniohjelmien luonti ja jakaminen muille käyttäjille
- Julkisten treeniohjelmien selaaminen ja kommentointi
